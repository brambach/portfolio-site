# Outside review of the portfolio

Reviewed on 5 September 2026 by a separate agent, then assessed against Bryce's feedback. The reviewer inspected the desktop journey and read the implementation. The follow-up audio review measured the files. A later driving review traced the stopping, lane and frame-time calculations. Neither review included a listening pass.

## Changes made from the review

- Removed the keyboard focus trap from the physical laptop. The site menu and sound controls remain reachable.
- Kept the selected project when the laptop closes and reopens. Internal project rows now use a chevron.
- Added a named project sticker to the laptop lid, a visible loading message and a separate `/projects` page that doesn't load Three.js or the forest.
- Saved mute and volume settings across visits.
- Added a physical front-seat racket and Bryce's supplied tennis memory.
- Changed the laptop movement to clear the seat before moving sideways. Object changes and exit wait for it to return.
- Moved the driving invitation onto the dashboard face, added a blank paper back and restricted its visibility to the cabin.
- Replaced the short repeating acceleration recording with a longer levelled engine bed. Matched the PCM endpoints and faded the mechanical one-shots. Continuing from a stop keeps the engine on.
- Added gradual tree-detail transitions and fern fades, with camera culling for tree groups. Compiled materials before revealing the scene.
- Added heading and a small chassis response to steering, acceleration and braking. Releasing the accelerator returns toward the scenic cruising speed.

- Replaced the laptop's promotional layout with a compact folder browser, made the tennis memory a ruled paper note and rebuilt the rear board as four taped photo prints. Kept Bryce's supplied tennis facts and the existing images.
- Replaced the abrupt final stop and sideways snap with continuous parking curves. Bounded the camera's acceleration response and kept rendering until the cabin settles. Fixed time steps keep a 15 fps simulation consistent with a 60 fps simulation.
- Replaced the laptop's nested 3D browser transforms with a projected reading layer. Coordinate clicks now work after travel. Closing a note restores keyboard control even when its menu button has been removed.
